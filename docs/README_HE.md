# חבילת התחלה — חנות אופנה עם קולבים אינטראקטיביים

## מה יש פה?
- `reference-frames/rack.png`: מצב קטלוג הקולבים מתוך הסרטון שהעלית.
- `reference-frames/detail.png`: מצב תצוגת מוצר מתוך הסרטון שהעלית.
- `reference-frames/return.png`: רגע נוסף באינטראקציה.
- `CLAUDE_PROMPT.md`: בקשה מוכנה לקלוד לייצר את האתר עצמו.
- `.claude/skills/fashion-rack-experience/SKILL.md`: סקיל אופציונלי לקלוד קוד, עם סטנדרט עיצוב ופיתוח.

## הדרך הכי קלה להתחיל
1. היכנס ל־https://claude.com/code והתחבר לחשבון שלך (בהתאם לזכאות התוכנית שלך).
2. צור מאגר חדש ונפרד ב־GitHub בשם `interactive-fashion-store`, או פרויקט חדש בטאב Code של Claude Desktop.
3. חלץ את הקובץ הזה לתיקיית הפרויקט. אם אתה עובד בענן עם GitHub, הוסף את הקבצים למאגר חדש ופתח אותו ב־Claude Code.
4. פתח את `CLAUDE_PROMPT.md`, העתק את הבקשה אל Claude Code ושלח.
5. בקש מקלוד להפעיל את סביבת הפיתוח ולהראות לך תצוגה מקדימה. בדוק גלילה, לחיצה על בגד, חזרה, סל קניות ומסך טלפון.
6. רק אחרי שההדגמה עובדת, מחברים Shopify דרך Storefront API ופורסים ב־Vercel.

## איך הסקיל עובד?
הסקיל הוא תיקייה עם קובץ `SKILL.md`. Claude Code יודע לגלות סקילים בתיקיית `.claude/skills/` של הפרויקט. תוכל לבקש: 'Use the fashion-rack-experience skill to implement/refine the experience.' הסקיל אינו תוסף שצריך לרכוש ואינו מחליף בדיקות או תמונות אמיתיות.

## מה כדאי לדעת
- התמונות הן צילומי ייחוס מסרטון מסך, לא תמונות מוצר לשימוש מסחרי.
- לבניית חנות מסחרית צריך תמונות בגדים מורשות, תיאורי מוצרים, מידות ומחירים, וחשבון Shopify תקין.
- אל תוסיף מפתחות API פרטיים למאגר GitHub, לקוד דפדפן או לקובץ משותף.
- חיבור Shopify כ־headless עשוי להצריך יותר תחזוקה מאשר עיצוב רגיל בתוך ערכת נושא של Shopify.
